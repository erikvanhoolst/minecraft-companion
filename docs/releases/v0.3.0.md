Eerste publieke release van de Minecraft-companion voor Eden Duo.

## Download en installatie

Download **`0100D71004694000.dsmod.zip`** bij de assets hieronder. Dit is het installatiepakket; de automatisch aangeboden source code-archieven zijn voor ontwikkelaars.

1. Gebruik **Eden Duo 1.1.0 (runtime 18) of nieuwer**.
2. Houd Minecraft ingedrukt en kies **Add-ons → Install → Dual screen mods**. Selecteer de gedownloade zip.
3. Zet de Minecraft-update uit en start **Minecraft 1.2.12**, de basisgame zonder update.
4. Open een wereld. Het onderste scherm toont je inventory; via de tab **Map** open je de kaart.

De zip bevat modules voor **Android arm64** (zoals de AYN Thor) en **Linux x86_64** (desktop). Er zitten geen spelbestanden in: iconen, lettertype en kaartmateriaal worden uit je eigen game gelezen.

## Functies

- Live inventory met 27 vakken, 9 hotbar-vakken, itemiconen, aantallen, selectie en itemnaam.
- Armor, health, lucht en honger zoals in de HUD van de game.
- Kaart van de geladen wereld rond de speler, met kaartkleuren, hoogteschaduw, waterdiepte en spelermarker.
- Coördinaten, kijkrichting en kaartzoom van 64, 128 of 256 blokken.
- Wisselen tussen Inventory en Map via tabs of een veegbeweging.

## Compatibiliteit en beperkingen

- **Minecraft 1.2.12**, build `D8B7E605E809E80C`: inventory eerder getest op AYN Thor en pc; HUD, itemnamen en kaart eerder getest op pc.
- **Minecraft 1.26.13 / update v148**, build `53E6D516A4DA5CD0`: de module bevat ondersteuning, maar deze gameversie werkt niet in Eden Duo 1.1.0 en is niet gevalideerd. Voor deze build ontbreken HUD-balken en kaartondersteuning.
- Andere gamebuilds, Windows en macOS worden niet ondersteund door dit pakket.

## Integriteitscontrole

Download ook `SHA256SUMS` en controleer beide bestanden vanuit dezelfde map:

```sh
sha256sum --check SHA256SUMS
```

GitHub Actions bouwt beide modules en controleert pakketmetadata, architecturen, modulehashes, ABI-entrypoints en reproduceerbaar verpakken voordat de release wordt gepubliceerd. Een buildcontrole vervangt geen test in een draaiende game.
